# CabeçaTV · configuração remota

Arquivo público, só de leitura, que o app CabeçaTV baixa ao abrir para ligar/desligar
recursos ou tirar itens (por exemplo, a pedido de uma emissora) sem publicar versão nova.

- Endereço usado pelo app: `https://viniciusosc.github.io/cabecatv-config/config.json`
- O app não envia nenhum dado do aparelho; é um download simples.
- Só opções conhecidas e limitadas são aceitas (sem links, código ou HTML).

Pedidos de remoção de conteúdo: abra uma *issue* neste repositório.
